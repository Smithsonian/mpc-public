# Designations

Documentation related to minor planet and comet designation systems.

## Glossary

Provisional and temporary describe the role of a designation; packed and unpacked
describe how it is written. For example, a provisional designation can be written
in either packed or unpacked form.

| Term | Definition | Example |
|------|------------|----------------------|
| [Temporary designation](temporary-designations.md) | An identifier assigned by an observer or survey before the MPC assigns an official provisional designation. | `A7` (Flagstaff scheme) |
| [Provisional designation](provisional-designations.md) | An official identifier assigned by the MPC to a newly recognized object before it receives a permanent number. Note that occasionally two or more provisionally designated objects are later recognized to be the same underlying object and linked together. Through this process, objects can eventually end up with a "primary" and one or more "secondary" provisonal designations. For the same reason, not every assigned used provisional designation will have observations recorded in our database (the observations may be re-attributed to the primary designation instead). Also note that comets and minor planets have different designation systems, see below. | `1993 FT8` (This is the primary provisional designation; `1995 UW49` is a secondary provisional designation for the same object.) |
| Numbered object | A minor planet or comet with a sufficiently precise orbit that has been assigned a permanent number by the MPC. Only numbered objects are elligible for [naming](#naming), though naming is handled by [https://www.wgsbn-iau.org/](WGSBN), not the MPC. Once an object is numbered, it should be referred to by its number, not any provisonal designations.| `(12345)` (This is the number assigned to the object above.)|
| Named object | An object that has been assigned a name by the IAU. These are referred to by their number and name written together. | `(2531) Cambridge` |
| [Packed form](packed-designations.md) | A compact encoding of a provisional or permanent designation used in MPC data files. | `J95X00A` encodes `1995 XA`. |
| [Unpacked form](provisional-designations.md#unpacked-provisional-designations) | The human-readable form of a designation, with its year, letters, and numbers written out rather than encoded. | `1995 XA` is the unpacked form of `J95X00A`. |

Asteroid naming is handled by the IAU Working Group on Small Body Nomenclature (WGSBN), not by the MPC.
